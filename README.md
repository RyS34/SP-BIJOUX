SP-BIJOUX

Descripción del proyecto

SP-BIJOUX es una aplicación web en desarrollo creada como proyecto personal, orientada a la gestión y visualización de productos para una joyería.
La aplicación permite la interacción dinámica con la información de productos a través de diferentes módulos y pantallas, integrando tecnologías web y servicios en la nube para la gestión de datos.

Funcionalidades

- Visualización de catálogo de productos  
- Gestión y organización de información de productos  
- Interfaz web interactiva y responsiva  
- Navegación entre diferentes módulos de la aplicación  
- Integración con base de datos en la nube (Firebase)

Tecnologías utilizadas

- HTML  
- CSS  
- JavaScript  
- Firebase (Firestore / Realtime Database)
